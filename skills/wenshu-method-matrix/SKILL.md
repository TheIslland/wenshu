# 方法矩阵（Wenshu）

## 何时用

- 写方法章或文献综述，需要说明「既有研究怎么做、我为什么换一种做法」。
- 开题被问「你的方法和别人有什么不同」。
- 想找方法趋势，而不是凭印象说「近年转向」。

## 流程

1. **选文献。** 只选本地库中已读/在读的，标 `ref_id`；没读过的不要进矩阵。
2. **抽六列。** 每篇抽：`method`、`data`、`sample`、`theory`、`finding`、`limitation`。每个字段附一句原文证据；抽不到就写「未抽取」，不要猜。
3. **建矩阵。** 行=文献，列=六维；按方法/年份/理论筛选。
4. **看趋势。** 用本地库年份分布 + OpenAlex 年度计数；方法词频随时间变化。样本量太小就明说「不足以谈趋势」。
5. **找冲突。** 同一作者/同一样本/同一时期出现相反结论，标黄并回到原文核对，不替作者圆场。
6. **落到本文。** 最后回答：既有方法漏了什么，本文的方法补哪一块；不要写「本文方法更全面」。

## 硬规则

- 不从摘要之外的全文瞎推；没有全文就标「仅摘要」。
- 样本量、年份、方法名必须与原文一致；不确定就留空。
- 趋势结论必须给分母（共几篇、覆盖哪些年）。
- 中文文献覆盖不足时，明确说「本矩阵以英文/可获取文献为主」。

## 输出

1. 矩阵表（可导出 CSV/Markdown）；
2. 三条以内的趋势判断，每条带分母；
3. 冲突清单；
4. 「本文方法的位置」一段。
