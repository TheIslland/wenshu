# 文献综述（Wenshu）

## 流程

1. **定边界。** 写清三件事：时间范围、语种、材料类型（理论/经验/评论）。边界外的文献不放进综述，最多放进脚注。
2. **检索与去重。** 用文枢多源检索，DOI 优先去重；中文文献用 RIS/BibTeX/PDF/Zotero 补。把「没检索到」和「没收录」分开记。
3. **建抽取表。** 每篇至少六列：`作者/年`、`问题`、`材料与方法`、`核心判断`、`对本文有用的点`、`局限`。判断必须带原文证据句，不能只写摘要。
4. **按争论聚类。** 分成 2–4 条战线：
   - 谁把对象当作既定事实；
   - 谁把它当作被建构的；
   - 谁在解释机制，谁在描述现象；
   - 哪条线在什么条件下失效。
5. **写综述。** 每段一个判断，结构是「既有解释 → 证据 → 裂缝 → 本文接哪里」。禁止 A 认为、B 认为、C 认为的流水账。
6. **收口。** 最后一段必须回答：既有研究留下了什么**可被本文材料回答**的问题；不要写「研究较少，故本文重要」。

## 硬规则

- 每条文献陈述都要能落到本地库里的 `ref_id`；没有就标「待补」。
- 不把摘要改写成「作者认为」；能引原文就引，不能就写「据摘要」。
- 不用「填补空白」「首次提出」这类无法证伪的话。
- 同一作者不同时期的观点要分开，不合并成「某某认为」。
- 中文文献与英文文献的覆盖差异要写进方法或限制，不藏着。

## 输出格式

1. 战线图（3–5 行）；
2. 每段：判断句 + 证据 + 裂缝；
3. 缺口清单：每条注明「需要什么材料才能回答」；
4. 引用清单：只列真正用到的，标 `verified / unverified`。
