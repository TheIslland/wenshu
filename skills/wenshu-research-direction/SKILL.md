# 研究方向（Wenshu）

## 何时用

- 只有一个现象或理论词，不知道论文要回答什么。
- 开题报告被说「问题太大 / 没有缺口 / 材料撑不住」。
- 想换题，但不想丢掉已经读过的文献。

## 输入

至少给三样：领域/现象、时间范围、手头材料（文献、田野、文本、数据）。缺哪样就先问，不要猜。

## 流程

1. **先检索，后发问。** 用文枢检索 OpenAlex / Crossref / S2 / arXiv，按年份统计产量，记下 Top 期刊、Top 作者、反复出现的概念。中文文献覆盖有限，明确告诉用户「中文部分需要本地库/手动导入补」。
2. **找争论，不找空白。** 把文献分成 2–3 个立场：谁解释了 A，谁反驳了 B，谁把 C 当作前提。缺口写成「既有解释在 X 条件下失效」，不要写「研究较少」。
3. **生成 3–5 张问题卡。** 每张必须包含：
   - `question`：一句话，含对象、机制、材料边界；
   - `gap`：既有解释的裂缝，附支撑文献 ID；
   - `materials`：需要哪些文本/田野/数据，现在有没有；
   - `method`：可行方法（文本分析/民族志/访谈/比较/话语分析…）；
   - `risk`：最可能失败的地方；
   - `difficulty` / `novelty`：低/中/高；
   - `evidence_refs`：只能来自本次检索结果或本地库。
4. **排可行性。** 材料拿不到、伦理过不了、时间不够的，直接降级或删掉，不要为了「新颖」硬留。
5. **落项目。** 用户选中后，建项目、建文档、把问题卡拆成流程任务。

## 硬规则

- 不许编文献、页码、DOI。没有证据就写「待检索」，并在 `warnings` 里说明。
- 不把「理论意义/现实意义」当研究问题。
- 不承诺「填补空白」；只说明在什么材料与条件下，本文能推进哪一步。
- 中文文献的覆盖缺口要主动说，不能拿英文库的统计冒充中文研究现状。

## 输出

先给一页对比表（问题 / 缺口 / 材料 / 方法 / 风险 / 难度 / 新颖度），再展开每张卡。最后单列「需要用户补的材料」清单。
