# 段落调整（Wenshu）

## 四类操作

| 操作 | 做什么 | 不做什么 |
|---|---|---|
| `compress` | 删套话、合并同义句、拆掉总分总壳 | 不删证据、不删让步 |
| `expand` | 补解释、补证据、补机制 | 不补形容词、不补金句 |
| `reorder` | 主题句前置，旧信息→新信息，句尾放新信息 | 不改段落功能 |
| `argument` | 断言→证据→解释→让步四件套 | 没证据就进 gaps，不虚构 |

## 输入

段落本身、前后段、章节角色（综述/理论/个案/结论）、证据池、术语表、允许变动比例（默认 ±20%）。

## 流程

1. 先用一句话复述这段的**功能**（它在论证链里干什么）。功能不清就先问。
2. 标出不可动的东西：引用标记、引文、数字、术语、图表编号。
3. 按操作改写；每处改动写一句人话理由。
4. 校验：
   - 字数在 ±20% 内；
   - 引用与数字一个不少；
   - 没有新增原文/证据池之外的事实；
   - 段落功能没变。
5. 输出 diff、`ops`、`gaps`、`warnings`；缺证据的断言单独列，不要偷偷降级成模糊表述。

## 硬规则

- 不新增文献、页码、年份、场景、数据。
- 不把综述段改成个案段，不把结论段改成导论。
- 至少保留 1 句作者自己的判断，不能全段中性化。
- 不能为了「顺」加「值得注意的是」「不难发现」这类壳。
- 改完再跑一次风格规则；引入新问题就回退。

## 输出

`revised` + 逐条 `ops{type, span, reason}` + `gaps[]` + `diff`。最后问作者：哪一处改动改变了原意？
